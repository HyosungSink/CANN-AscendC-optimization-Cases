### What this PR does / why we need it?

This PR adds a built-in AscendC operator to optimize the QKV layout transformation in the Gated DeltaNet (GDN).

The GDN projection produces a token-major packed tensor:

```text
[Q0 K0 V0] [Q1 K1 V1] ...
```

The downstream recurrent and chunk GDN kernels consume three contiguous Q, K, and V tensors:

```text
[Q0 Q1 ...] [K0 K1 ...] [V0 V1 ...]
```

The existing PyTorch implementation splits the packed tensor, flattens the three non-contiguous views, and concatenates them. Profiling shows that this path launches three copy kernels followed by one concatenation kernel. The host-side dispatch chain delays submission of the following operators, while Q/K/V data is also copied through intermediate buffers.

This PR replaces that sequence with one AIC-only AscendC kernel. The kernel partitions token rows across cores and uses DMA `DataCopy` operations to move Q, K, and V directly to their final contiguous regions. The Python wrapper then creates the existing output views without additional NPU kernels.

The change includes:

- the `RearrangeQkvDma` AscendC kernel, host definition, and tiling implementation;
- registration in the vLLM Ascend built-in custom-operator build for A2 and A3;
- PrivateUse1 and Meta implementations for `torch.ops._C_ascend.npu_rearrange_qkv`;
- dispatch from the existing GDN path when the input is contiguous BF16 or FP16 and the Q/K/V widths satisfy the 32-byte DMA alignment requirement;
- fallback to the existing vLLM implementation on unsupported devices or layouts.

The mathematical operation, output shapes, and GDN state update order are unchanged.

### Does this PR introduce _any_ user-facing change?

No. There is no new API or configuration option. Supported GDN workloads select the optimized implementation automatically, while unsupported workloads keep the existing behavior.

### How was this patch tested?

The following coverage was added:

- CPU unit tests for A2/A3 dispatch and fallback on unsupported devices, dtypes, layouts, and alignments;
- A2/A3 NPU bitwise-copy tests over different token counts, storage offsets, and dynamic aligned Q/K/V widths;
- non-default-stream and NPU Graph capture/replay tests;
- direct operator-boundary validation and Meta dispatch coverage;
- reproducible Eager and NPU Graph microbenchmarks.
