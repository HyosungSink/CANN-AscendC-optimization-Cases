### What this PR does / why we need it?

Add a bit-preserving AscendC mHC expansion operator from `[tokens, hidden]` to
`[tokens, mult, hidden]`, integrated with the existing GLM inference call site on A2.

- Balance contiguous row ranges across cores and group row copies. Wide unaligned
  output tiles own disjoint 32-byte intervals, fixing the original tail regressions.
- Reduce eager dispatch overhead with cached extension availability and asynchronous
  ACLNN dispatch. Snapshot tensor metadata and retain storage until launch. Preserve
  the existing adapter for core controls and convert non-base storage to ND.
- Add strict validation, optional dispatch, symbolic Meta, fallback/autograd coverage,
  stream/lifetime/storage-format tests and reproducible profiler/wall/graph benchmarks.
- Synchronize profiler boundaries and reject traces with missing or extra calls.

### Does this PR introduce _any_ user-facing change?

Default custom dispatch is limited to A2, contiguous nonempty FP16/BF16 tensors,
width divisible by 16, **at most 1024 tokens**, mult=4, without gradients.
Other inputs use native expansion. The raw operator also supports larger token counts,
positive multipliers and unaligned widths. No configuration flags are added; contraction
is unchanged.

The token limit is intentional: 3500-token eager batches regressed in the earlier
unrestricted candidate, including a five-round, 1000-call confirmation. Although that
candidate improved device/graph timing, the final default path keeps larger batches on
native expansion in both eager and graph modes. The final tables include those fallback
cases and their remaining dispatcher overhead rather than dropping them.

#### Performance methodology and results

Primary tables include three independent rounds, alternating implementation order. The
additional large-batch confirmation uses five rounds of 1000 calls. Profiler
runs have five warmup and exactly five active invocations; every CSV count is asserted.
Device time sums all operator rows per invocation. Wall/graph timing synchronizes around
100 calls; graph capture and correctness checks are outside the timed interval.
Median times and the median of paired per-round native/PR ratios are reported separately;
the latter need not equal the quotient of the time medians. Ranges are observed round
variation, not confidence intervals. `PR path` includes native fallback above 1024 tokens.
`repeat()` is included as an additional comparison; the production baseline is
`expand().contiguous()`. No full-model throughput improvement is inferred.

- Latest GLM wall timing at <=1024 tokens: median native/PR ratios **1.177–1.210x**.
  At 3500/8192 tokens, native fallback is near baseline with approximately 0–1% dispatcher
  overhead in the three-round run. Five rounds of 1000 calls give 3500-token ratios
  1.002x/1.003x and 8192-token ratios approximately 1.000x; the full confirmation table
  is included below.
- Final GLM device/graph geometric means are 1.342x/1.026x respectively. Graph timing
  includes three cases with median ratios below 1; it does not establish universal gains.
- Raw kernel results are explicitly from `273e2a9`, before the dispatch-only limit;
  raw operator/device source and installed kernel hashes are unchanged. Across 22 cases,
  the geometric mean of median paired ratios is **1.512x**. The original width-8193
  tail cases are **1.468x FP16 / 1.491x BF16**. Some other cases are effectively tied;
  per-round slowdowns remain visible below.
- The latest GLM profiler matrix contains 144 independently checked five-call CSVs.
  Prior raw measurements contain 198 such CSVs. Earlier six-call traces were rejected,
  not divided by an assumed five.
